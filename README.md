## Features                                                                     
                                                                                
* 🔢 **Number Input** — Enter numbers from 0 to 9.                              
* ➕ **Addition** — Perform addition calculations.                              
* ➖ **Subtraction** — Perform subtraction calculations.                        
* ✖️ **Multiplication** — Perform multiplication calculations.                   
* ➗ **Division** — Perform division calculations.                              
* 🔢 **Decimal Numbers** — Perform calculations with decimal values.            
* ⌫ **Delete** — Remove the last character from the display.                    
* 🧹 **Clear** — Clear the current calculation.                                 
* ❌ **Exit** — Close the calculator application.                               
* 🚫 **Division by Zero Protection** — Prevent division by zero errors.         
* 🖥️   **Centered Window** — The calculator window is automatically positioned in the center of the screen.

## Installation & Setup                                                         
                                                                                
### Prerequisites                                                               
                                                                                
* **Python 3.8** or higher                                                      
* **pip**                                                                       
* **PySide6**                                                                   
                                                                                
### Quick Start                                                                 
                                                                                
1. **Clone the repository:**                                                    
                                                                                
   ```bash                                                                      
   git clone https://github.com/NarekMardoyan/Calculator.git                    
   cd Calculator                                                                
   ```                                                                          
                                                                                
2. **Install the required library:**                                            
                                                                                
   ```bash                                                                      
   pip install PySide6                                                          
   ```                                                                          
                                                                                
3. **Run the program:**                                                         
                                                                                
   ```bash                                                                      
   python Calculator.py                                                         
   ```
